# MetroPT-3 数据集

* **数据集名称：** MetroPT-3 压缩机空气产生单元（APU）运营多元时间序列数据
* **数据集类型：** 多元时间序列 / 工业物联网 / 异常检测与预测性维护
* **上传成员：** 2026anomaly

---

## 数据集说明

该数据集收集自实际运营环境中的地铁列车压缩机空气产生单元（APU）。数据跨度从 2020 年 2 月至 8 月，由车载嵌入式设备以 1Hz 的频率记录，包含 15169480 个数据点。

---

## 字段说明（15个特征传感器）

| 列名 | 含义 | 单位 | 类型 |
| :--- | :--- | :--- | :--- |
| **TP2** | 压缩机上的压力测量值 | bar | 模拟传感器 |
| **TP3** | 气动面板上生成的压力测量值 | bar | 模拟传感器 |
| **H1** | 旋风分离器过滤器排气时压降产生的压力测量值 | bar | 模拟传感器 |
| **DV pressure** | 干燥塔排气时产生的压降测量值（零表示在负载下运行） | bar | 模拟传感器 |
| **Reservoirs** | 储气筒下游压力测量值（应接近 TP3） | bar | 模拟传感器 |
| **Motor Current** | 三相电机一相的电流（0A关闭, 4A卸载, 7A负载, 9A启动） | A | 模拟传感器 |
| **Oil Temperature** | 压缩机上的油温测量值 | °C | 模拟传感器 |
| **COMP** | 进气阀电气信号（无进气时激活，表示关闭或卸载） | — | 数字传感器 |
| **DV electric** | 控制出气阀的电气信号（负载时激活） | — | 数字传感器 |
| **TOWERS** | 干燥塔及排水塔状态信号（不活动表塔1，活动表塔2） | — | 数字传感器 |
| **MPG** | 压力低于 8.2 bar 时在负载下启动压缩机的信号 | — | 数字传感器 |
| **LPS** | 压力降至 7 bar 以下时激活的检测信号 | — | 数字传感器 |
| **Pressure Switch** | 检测空气干燥塔排气的信号 | — | 数字传感器 |
| **Oil Level** | 压缩机油位检测信号（油位低于预期时激活） | — | 数字传感器 |
| **Cudal Impulse** | 计算从 APU 流向储气筒绝对空气流量的脉冲输出 | — | 数字传感器 |
