# HAI 安全数据集 (HIL-based Augmented ICS Security Dataset)

* **数据集名称：** HAI (HIL-based Augmented ICS) 工业控制系统安全数据集
* **数据集类型：** 多元时间序列 / 工业控制系统（ICS）/ 网络物理系统（CPS）异常检测与威胁识别
* **上传成员：** 2026anomaly
* **版权许可：** CC BY-SA 4.0

---

## 数据集说明

HAI 数据集收集自一个高度集成的真实工业控制系统（ICS）试验台（Testbed），该试验台通过硬件在环（HIL）仿真器模拟了**蒸汽轮机发电**与**抽水蓄能发电**过程。它包含了正常运行以及基于多种反馈控制回路（如 Emerson Ovation、GE Mark VIe、Siemens S7 等控制器）的复杂攻击场景下的多元时间序列数据，广泛用于网络物理系统及 ICS 端点异常检测研究。

---

## 核心物理过程与控制回路

试验台主要由四个核心部分组成：
1. **锅炉过程 (P1)：** 涉及低压、中温下的水-水热交换，由 Emerson Ovation DCS 控制（包含压力控制 PC、液位控制 LC、流量控制 FC、温度控制 TC、冷却控制 CC 等回路）。
2. **透平/涡轮过程 (P2)：** 模拟旋转机械行为，由 GE Mark VIe DCS 控制转速与振动监测。
3. **水处理过程 (P3)：** 模拟抽水蓄能电站上下水库间的水循环，由 Siemens PLC 控制。
4. **HIL 仿真器 (P4)：** 实时同步热力与水力发电模型，将三大物理过程在信号层高度耦合。

## 攻击场景类型

数据集中的攻击场景主要分为两大类：
1. **I/O 点攻击 (AP01 ~ AP47)：** 针对设定点（SPs）、过程变量（PVs）或控制变量（CVs）进行隐蔽操纵，包括短期/长周期扰动及维持历史传感器值。
2. **内部点攻击 (AE01 ~ AE08 - 仅限 23.05/HAIEnd)：** 直接篡改控制器内部算法模块（人工 I/O 初始化参数、算术校准曲线、高低阈值监视器），触发条件式隐蔽攻击。

---

## 数据格式与复现说明

* **文件格式：** 时间连续的 CSV 文件。首列为时间戳（`yyyy-MM-dd hh:mm:ss`），后续列为 SCADA 传感器点数与攻击标签列。
* **图结构数据 (Graph Data)：** HAI 23.05 提供配套的 Python NetworkX 图数据（JSON 格式），可用于**攻击传播链（APC，正向分析）**与**根因分析（RCA，反向分析）**研究。
