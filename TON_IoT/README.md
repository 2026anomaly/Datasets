# SWaT 数据集

数据集名称：TON_IoT

数据集类型：TON_IoT 数据集是新一代物联网（IoT）和工业物联网（IIoT）数据集，旨在评估基于人工智能（AI）的各类网络安全应用的保真度与效率。该数据集之所以被命名为“ToN_IoT”，是因为它包含了从多个异构数据源收集的数据：包括物联网与工业物联网传感器的遥测（Telemetry）数据集、Windows 7 和 Windows 10 以及 Ubuntu 14 和 Ubuntu 18 TLS 的操作系统数据集，以及网络流量（Network traffic）数据集。

数据集说明：
这些数据集采集自澳大利亚国防学院（ADFA）新南威尔士大学堪培拉分校（UNSW Canberra）工程与信息技术学院（SEIT）下属的 UNSW Canberra Cyber 物联网实验室所设计的一个真实、大规模网络环境。数据集通过并行处理的方式收集，以捕获来自物联网网络的多种正事件和网络攻击事件。物联网实验室开发了一个全新的测试床（Testbed），将众多虚拟机、物理系统、黑客攻击平台、云平台与雾计算平台以及 IoT/IIoT 传感器连接在一起，从而模拟工业物联网（IIoT）和工业 4.0（Industry 4.0）网络的复杂性与可扩展性。
1. IoT / IIoT 数据集：记录在日志（log）和 CSV 文件中，使用了超过 10种 IoT 和 IIoT 传感器（如气象传感器和 Modbus 传感器）来捕获其遥测数据。
2.  网络数据集(Network)：以数据包捕获（pcap）格式、日志文件以及 Bro 工具生成的 CSV 文件格式进行收集。
3.  Linux 数据集：通过在 Ubuntu 14 和 18 系统上运行追踪工具（特别是 atop）进行收集，用于记录磁盘、进程、处理器、内存和网络活动。数据记录在 TXT 和 CSV文件中。
4.   Windows 数据集：通过在 Windows 7 和 10 系统上执行性能监视器工具（Performance Monitor Tool）的数据集收集器进行捕获。原始数据集以性能监视器工具可打开的大型格式收集，并以 CSV 格式汇总记录磁盘、进程、处理器、内存和网络活动。
